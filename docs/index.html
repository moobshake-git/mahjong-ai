How it works

Four taps from "uh…" to a good move.

1

Enter your hand

Tap your 13 tiles before your turn. Ask for advice while the hand is still unplayed.

2

Add the new tile

The tile you drew, or the one another player just threw. Advice updates straight away.

3

Get the call

One clear move: discard, pong, chow, kong, win or pass, with a one-line reason.

4

Watch for your tiles

See which tiles finish a hand that pays, and how many are still out there.

Get started

Up and running in a minute.

You need Python 3.10 or newer. Nothing else to install.

  • Opens at localhost:8000 in your browser.
  • Add --host 0.0.0.0 to use it from your phone on the same Wi-Fi.
  • To let Jev choose moves, copy .env.example to .env and add your key.
# get the code
git clone https://github.com/moobshake-git/mahjong-ai.git
cd mahjong-ai

# optional: turn Jev on
cp .env.example .env

# start the coach
python -m mahjong_coach serve
